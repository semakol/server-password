# Server Password

Пароль для каждого игрока на оффлайн-сервере (`online-mode=false`), где ник ничем не подтверждён и
занять чужой может кто угодно.

NeoForge 1.21.1. Мод нужен **и клиенту, и серверу**.

## Зачем это нужно

На сервере с `online-mode=false` никто не проверяет, кто вы. Ник — просто строка, которую клиент
присылает при входе, и сервер верит ей на слово. Любой может назваться вашим ником и зайти как вы:
ваш инвентарь, ваш дом, ваши права оператора. Ванильными средствами это не лечится — белый список
не пускает посторонних, но не мешает уже впущенному игроку войти под чужим ником.

Мод добавляет то, чего не хватает: пароль, привязанный к нику. Первый вход закрепляет ник за
паролем, который игрок задал в клиенте; дальше зайти под этим ником без того же пароля нельзя —
сервер отключает ещё до попадания в мир.

При этом пароль не передаётся по сети и не хранится на сервере: сервер держит только производную от
него, по которой войти можно, а сам пароль восстановить нельзя (см. «Как это работает»).

## Как это выглядит для игрока

1. Пока пароль не задан, «Сетевая игра» открывает меню ввода пароля вместо списка серверов —
   каждый раз, а не только при первом заходе. «Сохранить» ведёт в список серверов, «Назад» — обратно
   в главное меню. Когда пароль задан, список открывается как обычно, а кнопка **«Пароль»** в правом
   верхнем углу списка позволяет его перезадать.
2. Вводит пароль один раз; он используется для всех серверов с этим модом.
3. Первый вход на сервер регистрирует пароль за этим ником.
4. Дальше вход с этого ника возможен только с тем же паролем — иначе игрока отключает
   ещё до попадания в мир.

## Как это работает

На оффлайн-сервере шифрование пакетов не включается (оно часть авторизации Mojang), поэтому пароль
по сети **не передаётся**:

| | |
|---|---|
| Клиент | растягивает пароль в 32-байтный ключ: PBKDF2-HMAC-SHA256, 210 000 итераций, соль от сервера |
| Сервер | хранит этот ключ как верификатор и на каждый вход присылает свежий одноразовый `nonce` |
| Клиент | отвечает `HMAC-SHA256(ключ, nonce)` |

Сам ключ уходит на сервер только один раз — при регистрации ника. Дальше каждый вход подтверждается
одноразовым ответом, так что перехваченный вход нельзя переиграть.

Проверка идёт в configuration-фазе подключения, до создания игрока в мире. Пакеты зарегистрированы
как обязательные, поэтому ванильный клиент без мода сервер не пустит — пароль не обойти, просто не
поставив мод.

## Файлы

| Файл | Что внутри |
|---|---|
| `<мир>/serverpassword/passwords.json` | ник → соль, число итераций, верификатор. Пароля там нет |
| `config/serverpassword-local.json` (клиент) | пароль игрока, **без шифрования** |
| `config/serverpassword-server.toml` | `allowNewRegistrations` — можно ли новым никам регистрироваться |

Для отдельного мира конфиг можно переопределить файлом `<мир>/serverconfig/serverpassword-server.toml`.

Клиентский файл лежит в открытом виде: пароль нужен как вход для KDF при каждом входе, и спрятать
его от того, у кого есть доступ к папке игры, всё равно нельзя. Модель доверия та же, что у
сохранённой сессии лаунчера.

Серверный `passwords.json` пароли не раскрывает (PBKDF2 необратим), но верификатора достаточно для
входа — храните его так же аккуратно, как `ops.json`.

Если `passwords.json` не читается, сервер **никого не пускает** и не перезаписывает файл: иначе
повреждённый файл молча снял бы защиту и позволил занять любой ник заново.

## Команды (только оператор, уровень 3)

```
/serverpassword list
/serverpassword reset <ник>
```

`reset` стирает пароль ника (и отключает его, если он онлайн) — следующий вход задаст новый.
Задать или прочитать пароль командой нельзя: сервер его не знает, а в чате он попал бы в логи.

## Как сбросить пароль

Главное: **сменить пароль в одиночку игрок не может.** Кнопка «Пароль» меняет только то, что хранит
клиент, а сервер по-прежнему ждёт старый — после такой «смены» игрока просто не пустит с сообщением
«Неверный пароль». Смена и восстановление всегда идут через оператора.

### Игрок забыл пароль или хочет его сменить

1. Оператор на сервере: `/serverpassword reset <ник>` — стирает запись (игрока выкинет, если онлайн).
2. Игрок: кнопка **«Пароль»** → вводит новый → «Сохранить» → заходит на сервер.
3. Этот вход регистрирует новый пароль за ником, как самый первый раз.

Порядок важен: если игрок задаст новый пароль до сброса, сервер его не пустит.

### Нет доступа к чату сервера

При **выключенном** сервере откройте `<папка мира>/serverpassword/passwords.json` и удалите объект
нужного ника внутри `"players"`. Чтобы сбросить всем, удалите файл целиком — он создастся заново.

Правьте только на остановленном сервере: запущенный держит содержимое в памяти и перезапишет файл
при следующей регистрации.

### Убрать пароль на своём клиенте

Удалите `config/serverpassword-local.json` в папке игры. Это забывает пароль только у клиента; запись
на сервере остаётся, и войти получится, лишь введя тот же пароль снова.

## Что мод не делает

- Не защищает от подбора: ограничения на число попыток нет, только запись в лог.
- Не даёт игроку сменить пароль самому — нужен `/serverpassword reset` от оператора.
- Ошибиться при первом вводе = зарегистрировать опечатку. Лечится тем же `reset`.
